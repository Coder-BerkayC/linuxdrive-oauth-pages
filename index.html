LinuxDrive Personal Sync

LinuxDrive Personal Sync is a personal, noncommercial desktop configuration that uses rclone to synchronize files between the owner's Linux computer and the owner's Google Drive account.

The primary use is to archive scientific computation outputs, plots, and diagnostic reports. Google authorization takes place through OAuth. Files are handled locally and through Google's Drive service. This is not a publicly offered file hosting service.

This is an independent personal setup, not an official Google or rclone product.
