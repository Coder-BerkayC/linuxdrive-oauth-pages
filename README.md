# LinuxDrive Personal Sync

Public informational pages for a personal Google OAuth Desktop client used with rclone.

## Files

- `index.html`: application home page.
- `privacy.html`: privacy policy.

No client secrets, OAuth tokens, configuration files or private Google Drive data belong in this repository.

## Publish with GitHub Pages

1. Open **Settings > Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. Open the URL displayed by GitHub Pages and verify both the home page and privacy policy work.
5. In **Google Cloud > Google Auth Platform > Branding**, enter the verified Pages URLs, save the changes, then return to **Audience** to publish the OAuth app.

The Google OAuth application is for personal use. Review the privacy policy if the actual data handling changes.
