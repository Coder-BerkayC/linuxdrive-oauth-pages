Privacy Policy

LinuxDrive Personal Sync is a private, noncommercial rclone configuration used by its owner to transfer files between a Linux computer and the owner's Google Drive.

Data accessed

After the owner grants Google OAuth permission, rclone may list, read, create, update, and, if the granted permission permits, delete files in the authorized Google Drive account. The intended workflow is to upload and verify research simulation results.

Data use and storage

Google Drive file data is accessed only to perform transfers and file verification requested by the owner. OAuth authorization credentials are maintained in the owner's local rclone configuration. The owner controls the device, the files transferred and the Google account authorization.

Sharing

This personal setup does not operate a separate application server or sell Google user data. Files are transferred between the owner's computer and Google's Drive service. No other third-party destination is configured as part of this setup.

Control and revocation

The owner can stop using the tool, remove its local configuration, or revoke its access through the Google Account security settings. Revoking access stops future authenticated transfers; it does not automatically delete files already stored in Google Drive.

Changes and questions

This policy describes the current personal configuration. If data practices change, this page should be updated before the changes are used. For questions, use the developer contact information provided on the Google OAuth consent screen.
